# Blueprint Técnico Final: UI/UX AntroSapiens V4
**Documento de Especificación de Arquitectura Front-End**
**Sistema:** Instrumento Científico de Campo
**Entorno:** Android (First-Mobile)

---

## 1. Fundamentos Ontológicos del Renderizado

| Elemento | Especificación | Regla de Implementación |
| :--- | :--- | :--- |
| **Fuente Narrativa** | Newsreader (Serif) | Análisis, peritaje y juicio humano. |
| **Fuente Técnica** | JetBrains Mono (Mono) | Hashes SHA-256, IDs y extracción cruda de IA. |
| **Fuente Interfaz** | Inter (Sans-Serif) | Navegación, botones y metadatos de UI. |
| **Ancho Editorial** | max-width: 65ch | Límite estricto para prevenir fatiga visual. |
| **Superficie (Día)** | Parchment (#FCFAED) | Prohibido blanco puro (#FFFFFF). |
| **Superficie (Noche)** | Parchment Dim | Prohibido negro puro (#000000). |

## 2. Ergonomía Táctil y Estructura (Android)

*   **Zona de Pulgar:** BottomNavBar y acciones críticas ancladas en el tercio inferior.
*   **Precisión:** Áreas táctiles mínimas de 48dp (w-12 h-12).
*   **Anclaje Cognitivo:** Sticky header colapsable para la "Pregunta Antropológica" (Nivel 2).
*   **Iconografía:** Glifos abstractos metodológicos (Observación, Descripción, Análisis, Teoría).

## 3. Blindaje Metodológico y Estados

*   **Regla G0 (Cero Saltos):** Bloqueo visual de Nivel 3 si N1 o N2 están vacíos.
*   **Microinteracciones:** "Sellar Peritaje" requiere `onLongPress` (1000ms) o `onSwipe`.
*   **Trazabilidad:** Revelación de Hash SHA-256 en máximo 2 taps desde cualquier evidencia.
*   **Saturación Orgánica (N1):** Shader dinámico de "Feedback Mineral" basado en el volumen del corpus.

## 4. Gestión de Alertas (Baja Fricción)

*   **Bloqueo/Error:** Inline o Toast (Terracota/Arcilla) - "Fricción de sincronización".
*   **Advertencia:** Inline o Toast (Ámbar mineral) - "Evidencia en cuarentena".
*   **Éxito:** Desvanecimiento suave (Oliva/Neutro) - "Peritaje sellado".
*   *Nota: Prohibido el uso de ventanas modales bloqueantes.*

## 5. Restricciones de Compilación (Anti-Patrones)

*   **No Comercial:** Prohibido: leads, funnel, conversión.
*   **No Forense:** Prohibido: terminología criminalística.
*   **No Cuantitativo:** Prohibido: gráficas de barras, pastel, KPIs.
*   **No Semafórico:** Prohibido: Rojo alarma / Verde éxito tradicional. Todo es Mineral.
